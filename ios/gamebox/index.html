HOW TO PLAY

Press RUN to start. Use the directional pad to move and buttons I and II for game actions.

Hold a direction and either action button together. Slide your thumb around the pad for diagonals.

SAVE stores the current game state. LOAD restores it. I / II switches turn rapid fire on or off.

Touch the game screen to pause. Hold RUN and press SELECT to restart.

Keyboard: arrows · Z / X · A / S
