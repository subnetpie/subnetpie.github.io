PuP-Packs
Open the three .pup configuration files, a complete pack ZIP, or its media folder. Use PuP-Pack preview to inspect layouts, browse media, and fire events manually. Videos and images must be supplied locally. ZIP64 archives should be extracted first.
.zip
Open a ZIP containing one matching PAL/FSQ or PAL/VNI pair. The pair is unpacked locally and its scenes are listed automatically.
.fsq + .pal
Open both matching files together, or PAL first. FSQ v0–3 scenes are indexed from PAL mappings. Replacement scenes play independently. Color-mask scenes show stored planes and need source game frames for a complete image.
.pac
PAC v1–2 containers with embedded VNI v1–5 or FSQ v0–3 animations. Uses the automatic compatibility key, with an optional override for other keys.
.vni
Versions 1–5, including Heatshrink-compressed frames. Scenes are previewed as stored bitplanes.
.pal
PIN2DMD palette files, versions 1–2. Select a palette manually in Display settings.
.txt / .txt.gz
PinMAME-style hexadecimal frame dumps, with 128, 192, or 256 pixels per row. Timestamp timing is preserved.
.raw / .bin
Headerless frames. Choose the dimensions and byte layout before opening.
