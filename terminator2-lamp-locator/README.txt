TERMINATOR 2 — iPhone / iOS Files Lamp Locator

Included file: Terminator2_Lamp_Locator_iPhone_Safari.html

1. Save the ZIP to the iPhone Files app (Downloads or On My iPhone).
2. Open Files and tap the ZIP to unpack it.
3. Tap the HTML file. The lamp inventory is built into the file and should be visible even in limited previews.
4. Tap a lamp row to highlight it when Files Quick Look supports HTML fragment links/CSS.
5. For searching, filtering, map taps and navigation, view the HTML in a browser that allows JavaScript.

IMPORTANT iOS LIMITATION:
Apple Files may use Quick Look to preview a local HTML file and can limit scripts.
The option to open local HTML directly in Safari varies by iOS version and share sheet.
If you cannot open it in Safari, a hosted https:// URL (for example GitHub Pages)
is needed for the full interactive experience. Nothing in the HTML requires a network connection after loading.

Source: Williams Terminator 2 Judgment Day Operations Manual (1991).
Controlled lamps follow factory lamp positions; flashers/GI zone locations are approximate when the manual lacks precise coordinates.
