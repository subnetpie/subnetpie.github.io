# T2 Bulb Locator

[Open the tool](https://subnetpie.github.io/terminator2-lamp-locator/)

A bulb-focused reference for Williams Terminator 2: Judgment Day (1991).

## Use

Search by manual bulb label, name or family. Filter by Table / Backbox / Both and #44 / #89 / #555 / #906. Category buttons describe the lighting role: gameplay-controlled lamps, general illumination (GI), or flashers. Choosing a bulb family highlights supported drawing references. Previous and Next retain the active filters.

The list contains individual manual references and bulb groups, not a physical bulb count. Flashers are grouped by family and location. The backbox inventory lists 37 #555 bulbs and six #906 flashers (43 total) from the insert-panel parts list.

## Locations and replacements

Table markers identify features shown in the factory drawing; they are not inspected socket centers. Unverified flasher/GI positions are not plotted. The backbox offers an unannotated socket photo, a parts inventory, and a separate artwork reference.

LED advice follows bulb role and location. Inspect actual holders before ordering, especially the upper skull eyes (#555 wedge in the assembly drawing, #44 in the bulb chart) and table GI. The LED guide compares Comet, Tilt Graphics and Marco kits using linked supplier information.
